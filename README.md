<h1>📈 StockEdge(Zerodha-Clone) – Full Stack Stock Trading Platform</h1>

<h2>StockEdge is a full-stack stock trading web application that allows users to securely buy and sell stocks, track their portfolio, and visualize real-time stock data with interactive charts.</h2>


<b>🚀 Features</b><br><br>
<b>🔐 User Authentication</b><br>
   .Secure login/signup using JWT<br>
<b>💰 Buy & Sell Stocks</b><br>
  .Real-time trading functionality<br>
<b>📊 Stock Data Visualization</b><br>
  .Interactive charts using Chart.js<br>
<b>📁 Portfolio Management</b><br>
    .Track holdings and transactions<br>
<b>📱 Responsive UI</b><br>
  .Works seamlessly across devices<br><br>
<b>🛠️ Tech Stack</b><br><br>
<b>Frontend :</b><br>
.React.js<br>
.Material UI (MUI)<br>
.Tailwind CSS<br>
.Bootstrap<br>
.React Hook Form<br>
.Chart.js<br><br>
<b>Backend :</b><br>
.Node.js<br>
.Express.js<br>
.REST APIs<br><br>
<b>Database :</b><br>
.MongoDB<br><br>
<b>Authentication :</b><br>
.JSON Web Token (JWT)<br><br>

│
