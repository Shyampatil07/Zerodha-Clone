📈 StockEdge – Full Stack Stock Trading Platform

StockEdge is a full-stack stock trading web application that allows users to securely buy and sell stocks, track their portfolio, and visualize real-time stock data with interactive charts.

🚀 Features
🔐 User Authentication
Secure login/signup using JWT
💰 Buy & Sell Stocks
Real-time trading functionality
📊 Stock Data Visualization
Interactive charts using Chart.js
📁 Portfolio Management
Track holdings and transactions
📱 Responsive UI
Works seamlessly across devices
🛠️ Tech Stack
Frontend
React.js
Material UI (MUI)
Tailwind CSS
Bootstrap
React Hook Form
Chart.js
Backend
Node.js
Express.js
REST APIs
Database
MongoDB
Authentication
JSON Web Token (JWT)
